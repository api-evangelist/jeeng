## API Reference
- [Getting an access token](https://developers.jeeng.com/reference/getting-an-access-token.md)
- [Update](https://developers.jeeng.com/reference/management-line-update.md): Update a campaign line.
- [Update Status](https://developers.jeeng.com/reference/management-line-status.md): Update a campaign line status between running, paused and archived.
- [Update Status](https://developers.jeeng.com/reference/management-creative-status.md): Update a creative status between running, paused and archived.
- [Campaigns Report](https://developers.jeeng.com/reference/reporting-campaigns.md): Retrieve a campaign report with daily or hourly grain. The query and response are OData V4 format. The response may include a "next" link.
- [Campaign Lines Report](https://developers.jeeng.com/reference/reporting-campaign-lines.md): Retrieve a campaign line report with daily or hourly grain.
- [Advertiser Performance Report](https://developers.jeeng.com/reference/reporting-advertiser-performance.md): Retrieve a flexible advertiser performance report by specifying the fields, filters, and grouping you need.
- [Containers Report](https://developers.jeeng.com/reference/reporting-containers.md): Retrieve container reports with a daily grain.
- [Placements Report](https://developers.jeeng.com/reference/reporting-placements.md): Retrieve placement reports with a daily grain
- [Publisher Performance Report](https://developers.jeeng.com/reference/reporting-publisher-performance.md): Retrieve a flexible publisher performance report by specifying the fields, filters, and grouping you need.
